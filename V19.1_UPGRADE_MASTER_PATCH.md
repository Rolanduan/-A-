# V19.1 Upgrade Master Patch — GIS Preservation, Matrix Derivations, and Draw.io Standards

Status: additive upgrade to V19. This file supplements `V19_DECISION_LOCK.md`, `V19_EXPERT_COUNCIL_VISUAL_DIRECTIVE.md`, `V19_FIGURE_PROGRAM.csv`, and `V19_VISUAL_QUALITY_GATES.csv`. It does not overwrite or invalidate them.

## 1. Upgrade decisions now frozen

### 1.1 GIS preservation and detailed discussion
V19 shall preserve **all GIS figure families** through a two-tier output strategy:
- **Main-paper subset** for editorial clarity;
- **Complete GIS atlas** for full scientific record.

Every GIS map must be accompanied by a detailed discussion record using the template in `V19.1_GIS_ATLAS_AND_DISCUSSION_CONTRACT.md`.

### 1.2 Matrix derivations for graph-theoretic sections
All graph-theoretic content in V19 shall be restated in matrix form where appropriate, including:
- adjacency / incidence / Laplacian notation;
- shortest-path and thresholded access kernel matrices;
- category-aggregated opportunity matrix formulation;
- submodularity derivation for Algorithm II;
- edge-removal vulnerability derivation for Algorithm III.

The canonical additive appendix is `V19.1_GRAPH_THEORY_MATRIX_DERIVATIONS.md`.

### 1.3 Draw.io standard diagrams
All systems-style diagrams (Systems Architecture, Technical Route, algorithm workflows, evidence chain) shall use a Draw.io standard, editable source, and export workflow as defined in `V19.1_DRAWIO_STANDARD_AND_DIAGRAM_CONTRACT.md`.
