# V19.1 — Graph-Theory Matrix Derivations for the HiMCM A Research System

Status: **additive mathematical appendix** for V19. This file upgrades V19 and does not replace the existing scalar/network formulations.

## 1. Goal

All graph-theoretic sections in V19 shall be expressible not only in path-language but also in matrix language. This appendix defines the required matrix derivations for:

1. pedestrian-network representation;
2. shortest-path and accessibility operators;
3. facility-opportunity aggregation;
4. Algorithm II optimization kernel;
5. Algorithm III vulnerability / edge-removal analysis.

## 2. Base graph representation

Let the walkable urban network be a directed weighted graph
\[
G=(V,E,w), \qquad |V|=n,\ |E|=m,
\]
where each edge \(e=(u,v)\in E\) has nonnegative impedance \(w_e\) (distance or time).

### 2.1 Adjacency matrix
Define the weighted adjacency matrix
\[
A\in \mathbb{R}_{\ge 0}^{n\times n},
\qquad
A_{uv}=
\begin{cases}
\exp(-w_{uv}/\tau), & (u,v)\in E,\\
0, & \text{otherwise.}
\end{cases}
\]
For pure graph structure discussions, an unweighted binary adjacency matrix may also be used:
\[
B_{uv}=\mathbf 1((u,v)\in E).
\]
The weighted form above is useful because it already resembles accessibility decay.

### 2.2 Incidence matrix
Let \(M\in \{-1,0,1\}^{n\times m}\) be the directed incidence matrix:
\[
M_{ve}=
\begin{cases}
-1,& \text{if edge } e \text{ leaves } v,\\
+1,& \text{if edge } e \text{ enters } v,\\
0,& \text{otherwise.}
\end{cases}
\]
If \(W_e=\operatorname{diag}(w_1,\dots,w_m)\), then the combinatorial Laplacian is
\[
L = M M^\top,
\]
and a weighted variant is
\[
L_w = M W_e^{-1} M^\top
\]
(or an alternative positive diagonal scaling depending on convention).

### 2.3 Node classes and selection matrices
Let:
- \(R\subseteq V\) be residential / tract-anchor nodes,
- \(F\subseteq V\) be facility nodes,
- \(C\subseteq V\) be candidate intervention nodes.

Define selection matrices:
\[
S_R\in\{0,1\}^{|R|\times n},\qquad S_F\in\{0,1\}^{|F|\times n},\qquad S_C\in\{0,1\}^{|C|\times n},
\]
so that, for example, \(S_R x\) extracts the components of \(x\) indexed by residential nodes.

## 3. Shortest-path matrices

### 3.1 Pairwise shortest-path matrix
Define the all-pairs shortest-path matrix
\[
D\in (\mathbb{R}_{\ge0}\cup\{\infty\})^{n\times n},
\qquad
D_{uv}=\text{length of a shortest directed walk from }u\text{ to }v.
\]
At the research-engineering level, \(D\) is not formed densely for all \(u,v\); instead, it is computed implicitly by repeated truncated Dijkstra searches. But for derivations, it is the cleanest object.

Then the residential-to-facility distance matrix is
\[
D_{RF}=S_R D S_F^\top.
\]
Likewise, residential-to-candidate and residential-to-edge-endpoint relations can be written using analogous selection matrices.

### 3.2 Thresholded reachability kernel
For time threshold \(T\) and decay scale \(\tau\), define the accessibility kernel
\[
K(T,\tau)_{ij}=\mathbf 1\bigl(D_{RF,ij}\le T\bigr)\exp\left(-\frac{D_{RF,ij}}{\tau}\right).
\]
Thus
\[
K(T,\tau)\in\mathbb{R}_{\ge0}^{|R|\times |F|}.
\]
This is the matrix form of the tract-to-facility contribution rule.

## 4. Facility eligibility matrices

Suppose facilities are partitioned into categories \(k\in\{1,\dots,K\}\) (e.g., libraries and parks).
Let \(y\in\{0,1\}^{|F|}\) indicate confirmed public eligibility; let \(u\in\{0,1\}^{|F|}\) indicate unknown eligibility.
Then the **strict-access** facility mask is
\[
Y_{\text{strict}}=\operatorname{diag}(y),
\]
whereas the **upper-envelope** mask is
\[
Y_{\text{upper}}=\operatorname{diag}(y+u).
\]
This expresses the lower and upper access envelopes without treating unknown as confirmed public access.

If category membership is encoded by a matrix
\[
C\in\{0,1\}^{|F|\times K},
\]
then category-specific accessible opportunity from residential nodes is
\[
A^{(\ell)} = K(T,\tau)Y_{\ell}C,
\qquad \ell\in\{\text{strict},\text{upper}\}.
\]
Hence \(A^{(\ell)}\in\mathbb{R}_{\ge0}^{|R|\times K}\), and each row corresponds to one residence/tract anchor.

## 5. Tract-level opportunity and population aggregation

Let \(p\in\mathbb{R}_{\ge0}^{|R|}\) be the youth-proxy population vector (e.g., 15–17 ACS-derived tract population), and let \(\Omega=\operatorname{diag}(p/\sum p)\) be the normalized population-weight matrix.

If category weights are \(\lambda\in\mathbb{R}_{\ge0}^K\), then tract-level opportunity is
\[
a^{(\ell)} = A^{(\ell)}\lambda,
\qquad a^{(\ell)}\in\mathbb{R}_{\ge0}^{|R|}.
\]
The population-weighted mean opportunity is
\[
\bar a^{(\ell)} = \mathbf 1^\top \Omega a^{(\ell)}.
\]
This is the matrix version of the average access score.

For a lower-tail fairness statistic, let \(q_{0.1}(a,p)\) be the population-weighted 10th percentile and let \(\operatorname{CVaR}_{0.1}(a,p)\) be the population-weighted average over the lowest 10% by cumulative population. These are not simple matrix multiplications, but they are well-defined functionals on \((a,p)\).

## 6. Matrix interpretation of M1 access module

The access component of the reference model may be written abstractly as
\[
\Phi^{(\ell)} = 0.75\,\bar a^{(\ell)} + 0.25\,Q_{0.1}^{(\ell)},
\]
where \(Q_{0.1}^{(\ell)}\) is the weighted lower-decile summary. If the V19 upgrade adds CVaR as an auxiliary fairness diagnostic,
\[
\Psi^{(\ell)} = \operatorname{CVaR}_{0.1}(a^{(\ell)},p)
\]
becomes a companion statistic rather than a silent replacement.

## 7. Algorithm I in matrix language

Although the exact solver is Dijkstra-based, its target object is the sparse thresholded kernel \(K(T,\tau)\). V19 should present the algorithm as computing selected rows or columns of \(D\), then applying the nonlinear map
\[
D_{RF}\mapsto K(T,\tau).
\]
The forward-truncated formulation computes rows of \(D_{RF}\) from residential origins. The reverse-truncated formulation computes columns by running truncated Dijkstra on the reverse graph. The two strategies are algebraically equivalent in the sense that they seek the same entries of \(D_{RF}\); they differ only in computational route.

## 8. Algorithm II — facility placement as a set function with matrix kernel

Let candidate facilities be indexed by \(C\). For each candidate \(c\in C\), define its contribution vector at residential nodes as
\[
k_c\in\mathbb{R}_{\ge0}^{|R|},
\qquad
(k_c)_i = \mathbf 1(D_{RC,ic}\le T)\exp(-D_{RC,ic}/\tau),
\]
possibly category-specific.

Let the baseline opportunity be \(a^0\). For a chosen set \(S\subseteq C\), define added opportunity
\[
a(S)=a^0 + \sum_{c\in S} k_c.
\]
Using a concave, increasing saturation map \(\phi\), define the total objective
\[
F(S)=\sum_{i=1}^{|R|} \omega_i\bigl[\phi(a_i(S)) - \phi(a_i^0)\bigr],
\]
where \(\omega_i\ge0\) are frozen tract weights.

### Proposition (monotone submodularity)
If:
1. \(k_c\ge0\) componentwise for every candidate \(c\),
2. \(\omega_i\ge0\), and
3. \(\phi\) is increasing and concave,
then \(F(S)\) is monotone and submodular.

### Proof sketch
For any tract \(i\), the marginal gain of adding \(c\) to set \(S\) is
\[
\Delta_c^i(S)=\omega_i\left[\phi\left(a_i^0+\sum_{s\in S}k_{s,i}+k_{c,i}\right)-\phi\left(a_i^0+\sum_{s\in S}k_{s,i}\right)\right].
\]
Because \(\phi\) is concave and \(k_{c,i}\ge0\), \(\Delta_c^i(S)\) decreases as \(S\) grows. Summing over \(i\) preserves diminishing returns, so \(F\) is submodular. Monotonicity follows from nonnegative gains.

Thus, under a cardinality constraint \(|S|\le K\), classical greedy enjoys the \((1-1/e)\) guarantee.

This is the principal matrix-compatible optimization derivation that should appear in V19.

## 9. Algorithm III — edge-removal vulnerability in matrix language

Let edge \(e\) be removed, inducing graph \(G\setminus e\) and shortest-path matrix \(D^{(-e)}\). Then the new kernel is
\[
K^{(-e)}(T,\tau).
\]
Let resulting tract opportunities be \(a^{(-e)}\). Then the weighted opportunity loss due to edge \(e\) is
\[
R_e = \sum_i \omega_i\bigl(a_i-a_i^{(-e)}\bigr).
\]
If the focus is the lower-tail loss, define
\[
R_e^{\text{tail}} = \operatorname{CVaR}_{0.1}(a,p)-\operatorname{CVaR}_{0.1}(a^{(-e)},p).
\]
This creates a matrix-linked vulnerability measure grounded in actual recomputed path structure.

## 10. Systems architecture links

The matrix objects above should map directly onto systems diagrams:
- raw Census/TIGER/OSM layers -> selection matrices, population vector, graph matrices;
- routing engine -> shortest-path matrix operator;
- access engine -> thresholded kernel \(K\);
- scoring engine -> tract opportunity vector \(a\);
- optimization engine -> set function \(F(S)\);
- resilience engine -> perturbed kernel \(K^{(-e)}\).
